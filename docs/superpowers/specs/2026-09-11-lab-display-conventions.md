# 实验台显示与受力分析规范

**日期**：2026-09-11  
**状态**：已按推荐方案实施（斜面用实验室坐标；阿特伍德改进型补 μs）  
**目的**：把三条全项目约定写成可执行规则，后续所有力学实验、读数、公式、力图都按同一套做。

---

## 1. 这三条规则在说什么

| # | 原话 | 一句话落地 |
|---|---|---|
| 1 | 对所有的计算保留两位小数 | 学生看见的物理量一律 `0.00` 格式；内部积分仍用全精度 |
| 2 | 力学实验必须给出水平和竖直方向的分离 | 位移、速度、加速度、力都要拆成水平 / 竖直两支，不能只给沿斜面或合力 |
| 3 | 静摩擦和动摩擦按物体状态切换展示 | 同一时刻只展示当前分支：静止看静摩擦，滑动看动摩擦，离地则无摩擦 |

参考实现（已基本符合 1 和 3，部分符合 2）：斜向拉力 `pull-friction`。  
统一读数函数（已有，应成为唯一入口）：`formatLabNumber`（`components/lab-frame.tsx`）。

## 2. 适用范围

### 2.1 力学实验（规则 2、规则 3 的对象）

课程 `p1` 与 `c-mech` 中，凡涉及牛顿定律、运动学分量或接触力的实验，都算力学实验。当前 `ready` 列表：

| slug | 是否力学 | 规则 2（xy 分离） | 规则 3（摩擦切换） |
|---|---|---|---|
| `linear-motion` | 是 | 要（竖直分量为 0.00） | 否（无摩擦模型） |
| `projectile-motion` | 是 | 要 | 否 |
| `pull-friction` | 是 | 要（现状：Fx / Fz） | 要 |
| `incline-friction` | 是 | 要（现状缺实验室坐标分解） | 要 |
| `atwood-machine` | 是 | 要 | 改进型要（现状只有一个 μ） |
| `circular-motion` | 是 | 要 | 否 |
| `conservation-of-energy` | 是 | 要 | 否 |
| `impulse-momentum` | 是 | 要（竖直分量为 0.00） | 否 |
| `torque-equilibrium` | 是 | 要（力：水平 0.00 / 竖直为各重力） | 否 |
| `rotational-motion` | 是 | 要（质心的水平 / 竖直） | 有摩擦滚动时要 |
| `angular-momentum` | 是 | 落物阶段要 | 否 |
| `harmonic-motion` | 是 | 要 | 否 |
| `fluid-dynamics` | 是（流体力学） | 孔流射程：水平 R、竖直孔高 | 否 |
| `archimedes` | 是 | 要（浮力、重力均竖直；水平 0.00） | 否 |

`p2` / `c-em` 的电路、光学、热学实验：只遵守规则 1，不强制 xy 分离和摩擦切换。

新建力学实验默认三条全开。

### 2.2 规则 1 覆盖的界面

必须两位小数：顶栏 stats、场景旁 readouts、公式代入、状态栏里的数字、3D/2D 力图标签、图表当前值、力的讲解卡片。

不在此列：

- 仿真内部 `step` / 闭式解：保持全精度，只在显示时四舍五入
- 参数滑块：仍按 `step` 的位数显示（输入不是计算结果）
- 未知或刻意隐藏：继续用 `—`（例如抛体 B 模式未揭晓的 `|v|`）
- 渲染内部量：相机缓存 key、SVG path、trail 去重，不是学生读数

## 3. 规则 1：计算显示保留两位小数

### 3.1 做法

```ts
// 唯一入口。已存在，禁止再手写 toFixed(2) 的平行函数。
export function formatLabNumber(value: number) {
  if (!Number.isFinite(value)) return "—";
  const normalized = Math.abs(value) < 0.005 ? 0 : value;
  return normalized.toFixed(2);
}
```

带符号的分量（速度、力）用同一精度：`+1.20` / `-0.30`，不要 `toFixed(0)`。

### 3.2 对 / 错

```ts
// 错误：学生读数写成整数或三位
`${thetaDeg.toFixed(0)} °`
sample.a.toFixed(3)

// 正确
`${formatLabNumber(thetaDeg)} °`
formatLabNumber(sample.a)
```

公式代入与结果同一精度，例如 `G = 0.80 × 9.81 = 7.85 N`，不要一边三位一边两位。

### 3.3 现状差距

多数实验台和 `formatLabNumber` 已经是两位。需要收口的点：

- `projectile-measurement-board.tsx`：发射角仍 `toFixed(0)`
- `pull-friction-lab.tsx`、各 lab 里重复的本地 `formatNumber`
- 场景标签有的直接 `value.toFixed(2)`，应改走同一函数（行为不变，避免以后再分叉）

## 4. 规则 2：水平 / 竖直必须拆开

### 4.1 坐标约定

对学生：

- **x = 水平**（向右为正）
- **y = 竖直向上为正**

这与抛体实验、AP 教材一致。

实现细节：斜向拉力场景里 three.js 的竖直轴是模型里的 `z`（历史原因）。**标签仍写「竖直」**，符号用 \(F_y\) / \(a_y\) / \(v_y\) 对外；对内可以继续叫 `Fz`，但新实验不要再引入第三套名字。

### 4.2 必须同时出现的四组量

只要该实验有这项物理，就拆成水平 + 竖直：

| 量 | 水平 | 竖直 |
|---|---|---|
| 位移 | \(x\) | \(y\) |
| 速度 | \(v_x\) | \(v_y\) |
| 加速度 | \(a_x\) | \(a_y\) |
| 每个斜向力 | 虚线分力 | 虚线分力 |

合力、沿斜面分量可以**额外**给，但不能代替 xy。

一维实验（水平轨道、对心碰撞）竖直分量全部显示 `0.00`，并在公式里写明 \(v_y = 0\)，\(a_y = 0\)。不要省略竖直栏。

### 4.3 力图画法（沿用斜向拉力）

| 矢量 | 线型 | 何时出现 |
|---|---|---|
| 斜向合力（如拉力 F、斜面上的 mg 不必再画斜向合力） | 实线 | 合矢量本身存在且不是纯轴对齐 |
| 水平分力 | **虚线**，同色系更浅 | \(\lvert F_x\rvert \ge 0.005\) |
| 竖直分力 | **虚线** | \(\lvert F_y\rvert \ge 0.005\) |
| 已经沿轴的力（G、水平轨道上的 N、f） | 只画实线，不再拆虚线 | 分量过小则隐藏该箭头 |

画在物体同一起点，不要首尾相接成平行四边形。不画额外的 \(\sum F\) / \(ma\) 箭头。

读数栏至少包含：水平合力或 \(a_x\)，以及竖直方向的 \(N\) 或 \(a_y\)。图表在二维运动时至少各有一张水平、一张竖直时间序列（抛体已有 \(x(t)\)、\(v_x\)、\(v_y\)）。

### 4.4 斜面类实验的特殊要求

斜面摩擦、机械能守恒、滚动：学生既要沿斜面分析，也要看见实验室坐标：

1. **沿斜面 / 垂直斜面**（教学常用）：\(mg\sin\theta\)、\(mg\cos\theta\)、\(N\)、\(f\)
2. **水平 / 竖直**（本规则强制）：例如  
   \(N_x = N\sin\theta\)，\(N_y = N\cos\theta\)  
   \(f_x = -f\cos\theta\)，\(f_y = f\sin\theta\)（上滑/下滑符号按模型）  
   \(G_x = 0\)，\(G_y = -mg\)

只给 \(a = g(\sin\theta-\mu_k\cos\theta)\) 不够。

### 4.5 现状差距（相对本规则）

| 实验 | 已有 | 缺 |
|---|---|---|
| 斜向拉力 | 虚线 Fx/Fz、\(a_x\)/\(a_z\)、讲解卡片 | 对外符号仍混用 z |
| 抛体 | \(x\)、图表 \(v_x\)/\(v_y\) | 顶栏没有 \(y\)、\(v_y\)；无力的分解（无空气阻力时可只拆速度） |
| 斜面摩擦 | 沿面的 mg / N / f | 无 \(F_x,F_y\) 虚线；读数没有 \(a_x,a_y\) |
| 匀变速 / 冲量 | 只有沿轨 \(x\) | 未明示 \(y=0.00\) |
| 圆周 / 单摆 | 部分 \(x\) 与高度 | 绳张力未拆水平 / 竖直 |
| 阿特伍德 | 竖直位移 | 桌上滑车未拆水平拉力与竖直悬挂 |
| 简谐（弹簧） | 水平 \(x\) | 未明示竖直为 0；单摆张力未分解 |

## 5. 规则 3：静摩擦 / 动摩擦按状态切换

### 5.1 状态机（所有含摩擦的模型共用）

```
接触且 |v|≈0 且 |切向驱动力| ≤ μs N     → static   展示静摩擦
接触且正在滑 / 即将动（驱动力 > μs N） → kinetic  展示动摩擦
无接触（离地、N=0）                     → none     摩擦读数 0.00，不谈 μs/μk
滑行后停下且仍满足静摩擦条件           → static
```

\(\mu_k\) 永远 \(\le \mu_s\)（已有 `clampMuK`）。参数栏可以同时放 \(\mu_s\)、\(\mu_k\)；**读数、公式高亮、力图标签不能同时当成「当前摩擦力」**。

### 5.2 切换时学生必须看见的数据

**静止（static）**

- 标题：静摩擦力 \(f_s\)
- 当前值：\(f_s =\) 与驱动力平衡的值（水平面 \(f_s=-F_x\)，斜面 \(f_s=mg\sin\theta\)）
- 对照：最大静摩擦 \(f_{s,\max}=\mu_s N\)
- 公式：\(|F_{\parallel}| \le \mu_s N \Rightarrow a=0\)
- 不把 \(\mu_k N\) 写成当前摩擦力

**滑动（kinetic）**

- 标题：滑动摩擦力 \(f_k\)
- 当前值：\(f_k=\mu_k N\)，方向与速度相反（或与即将发生的滑动方向相反）
- 公式：\(f_k=\mu_k N\)，\(a\) 用动摩擦分支
- 可以灰字保留 \(f_{s,\max}\) 作对照，但标签不能再叫「当前 f」

**无接触**

- \(N=0\)，\(f=0.00\)，状态说明「无摩擦 / 无支持力」

### 5.3 界面怎么切

- 公式区：当前分支高亮（斜向拉力已有 static / sliding / airborne 背景）
- 力图标签：`f` → `fs` 或 `fk`（或中文「静摩擦 / 滑动摩擦」）
- 图表标题随状态改：静止画 \(f_s(t)\)，滑动画 \(f_k(t)\)，不要一条匿名 `f`
- 场景字幕：静止写「静摩擦平衡」，滑动写「滑动摩擦」

### 5.4 现状差距

| 实验 | 模型 | 展示 |
|---|---|---|
| 斜向拉力 | static / sliding / liftoff / airborne | 讲解卡片已切标题；readout 仍写裸 `f` |
| 斜面摩擦 | `stuck` 时用 \(mg\sin\theta\)，滑动用 \(\mu_k N\) | 公式始终同时写动摩擦加速度；标签只有 `f`；停下后 \(f=0\) 未标回静摩擦 |
| 阿特伍德（桌上滑车） | 只有一个 \(\mu\)，静止时 \(a=0\) | 无 \(\mu_s\)/\(\mu_k\)，无法按状态切换 |

## 8. 请你拍板的两点

下面两处会改变斜面和阿特伍德的工作量，需要你选一个方向：

**A. 斜面的「水平和竖直」**  
推荐：实验室坐标强制拆开（\(G_x=0\)，\(N\) 和 \(f\) 再画虚线 Fx/Fy），沿斜面公式保留。  
备选：只拆重力到沿面 / 垂直面，不画实验室 xy。

**B. 阿特伍德桌上滑车**  
推荐：补 \(\mu_s\) 与静止判定，才能真的切换静 / 动摩擦。  
备选：继续一个 \(\mu\)，只在「已动」时显示动摩擦，静止时写「静摩擦足以平衡」但不给 \(f_s\) 数值。
