# Physics Lab 结课修订设计规格

**日期：** 2026-10-14  
**状态：** 已确认  
**范围：** 物理模型、实验场景、时间图、窄屏布局、审查归档与结课文稿

## 1. 目标

本轮修订解决 2026-10-14 作品检查中记录的五类问题，并补齐圆锥摆的非平衡动力学。修改应保留现有 40 个实验的课程结构和学术仪器风格，也应保留工作树中已有的首页预览性能优化。

验收结果包括：

1. 竖直圆周在绳张力降到 0 时转入抛体运动。
2. 圆锥摆在非平衡初值下真实改变张角。
3. 孔流装置、水位、水舌和落点清晰可见。
4. 力的数值标签不再压在物体上，目录缩略图不堆叠完整力图。
5. 时间图使用数据自身的纵轴范围，并显示最近一段时间。
6. 375-400 px 窄屏下，考纲、三维场景和关于页都可读。
7. 仓库包含可复核的审查材料、项目入口文档和完整项目报告。

## 2. 设计方向

本项目属于面向学生和教师的交互式物理实验工具。本轮属于保留式改版，不更换信息架构、课程名称、路由或品牌视觉。

- Design variance: 4/10
- Motion intensity: 3/10
- Visual density: 6/10
- 颜色：沿用海军蓝、金色强调、冷灰背景
- 字体：沿用现有无衬线正文与等宽数字
- 形状：沿用 8-12 px 圆角与细边框
- 动效：只保留状态反馈和物理运动，不增加装饰动画

## 3. 物理模型

### 3.1 竖直圆周

竖直模式按绳约束处理。受约束阶段使用

`φ̈ = -(g/R) sinφ`

并计算

`T = m(v²/R + g cosφ)`。

模型寻找张力首次从正值降到 0 的事件。事件发生后记录脱轨时刻、位置和切向速度，后续按二维抛体闭式解更新位置和速度。低速且张力始终为正时允许来回摆荡；`v₀ >= √(5gR)` 时允许完整过顶。

场景在脱轨后隐藏绳和张力箭头，显示抛物轨迹。不能完整过顶但会脱轨的情况只画从底端到脱轨点的圆弧。

### 3.2 动态圆锥摆

圆锥摆使用 spherical pendulum 状态：

`θ, θ̇, φ, φ̇`

运动方程为：

`θ̈ = sinθ cosθ φ̇² - (g/L) sinθ`

`φ̈ = -2 cotθ θ̇ φ̇`

初始张角来自 `thetaDeg`，初始极角速度为 0，初始方位角速度由切向速度 `v₀/(L sinθ)` 决定。平衡初值保持定角；非平衡初值产生真实升降与章动。模型使用固定步长 RK4，并以总机械能和绕竖直轴角动量漂移作为回归约束。

动态张力使用：

`T = mL(θ̇² + sin²θ φ̇²) + mg cosθ`。

## 4. 统一数据流

每个动画帧产生一个 sample。页头 stats、状态文案、三维场景、底栏 readouts、轨迹和图表当前标记只读取该 sample，不分别重算当前状态。

`CircularSample` 增加：

- `phase: "constrained" | "projectile"`
- `polarVelocity`
- `detachment`

水平圆周保持现有匀速模型。竖直圆周与圆锥摆通过同一外层分派返回统一结构。

## 5. 图表

纵轴只根据当前可见数据计算最小值和最大值，并在两端增加 8% padding。常量非零序列围绕该常量展开，不强制把 0 放入范围。只有可见范围跨过 0 时才画零线。

横轴采用滑动窗口：

- 一般实验：最近 10 秒
- 周期运动：最近约 3 个周期
- 尚未填满窗口时：从 0 开始

窗口保留边界前一个采样点，保证折线进入窗口时连续。

## 6. 场景与标注

共享 `VectorArrow` 支持外置标签锚点与短引线。斜面、圆周和阿特伍德场景为各力提供稳定偏移，标签不得覆盖质量块或摆球。

目录预览使用现有 `LabPreviewMode`。预览只保留装置、轨迹和运动，不渲染完整受力箭头与数字标签。

孔流场景保留现有托里拆利计算，重画以下视觉元素：

- 高对比透明水箱
- 与参数 `H` 对应的独立液面
- 清晰孔口
- 连续实线或带状水舌
- 落点与射程标记

## 7. 响应式布局

小于 640 px 时，首页和关于页的考纲表切换为一单元一块的列表。中文标题、英文名称与占比分行显示。

小于 768 px 时，实验台视觉顺序为：

1. 三维场景
2. 参数与公式
3. 时间图

三维区域使用明确的响应式高度，最低不小于 320 px。桌面三栏和 1280×720 cockpit 保持不变。
