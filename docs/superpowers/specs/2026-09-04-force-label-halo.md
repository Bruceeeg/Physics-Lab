# 力标注去底方案

**日期**：2026-09-04  
**状态**：已确认并实施  
**范围**：只改 3D 力标签的 DOM 样式；不改物理、箭头、错开规则。

## 问题

当前标签是白底圆角块（`bg-white/90` + 内边距）。数字虽然清楚，但在网格上像挖出一块空白，破坏实验台画面。

## 做法

- **去掉底**：不要背景、不要内边距色块、不要圆角底板。
- **字本身鲜明**：继续用现有饱和色 + 名称 semibold、牛顿数 bold。
- **可读性靠字形描边**：浅纸色细描边（约 0.65px `#F1F5F9`）+ 四向 1px `#E2E8F0` 阴影，只贴着笔画，不铺矩形。

备选不采用：半透明毛玻璃底板（仍是一块）；纯无描边（叠在网格上发糊）。
